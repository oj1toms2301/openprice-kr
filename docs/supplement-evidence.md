# 영양제 근거자료 작성 원칙

`openprice-kr`의 영양제 리포트는 가격 비교를 중심으로 하되, 사용자가 제품을 이해하는 데 필요한 최소한의 근거 요약을 함께 보여줍니다.

이 문서는 영양제 원료 정보를 공개 샘플 데이터에 넣을 때의 기본 원칙을 정리합니다.

## 기본 원칙

- 가격 비교가 주 기능이며, 효능 설명은 보조 정보로 다룹니다.
- 효능을 단정하지 않고, 근거 수준과 확인 필요 여부를 함께 표시합니다.
- 의료 조언, 진단, 치료 권고처럼 보일 수 있는 표현은 피합니다.
- 공식 자료, 논문, 제품 라벨, 사용자 후기의 성격을 구분합니다.
- 후기에서 자주 보이는 반응은 개인 경험으로만 다루며, 효능 근거로 쓰지 않습니다.

## 리포트에 표시하는 정보

영양제 원료 요약은 다음 정보를 우선합니다.

- 원료명
- 공식 기준 확인 결과
- 효능/근거 요약
- 주의사항
- 후기에서 자주 보이는 반응
- 참고자료

공식 기준 확인 결과에는 한국 식약처, 미국 FDA, 미국 NIH ODS, 미국 FTC 기준을 필요에 따라 표시합니다.

각 기준은 사용자가 따로 공부하지 않아도 이해할 수 있도록, 판정 결과 바로 아래에 다음 세 가지를 함께 적습니다.

- `consumerQuestion`: 사용자가 실제로 궁금해할 질문
- `consumerAnswer`: 그 질문에 대한 짧은 답
- `buyerValue`: 구매할 때 이 정보가 왜 도움이 되는지

예시:

- 한국 식약처: 한국 건강기능식품에서 기능성 표시가 공식 인정됐는지 보는 기준
- 미국 FDA: 일반 영양제를 의약품처럼 사전 승인하지는 않으며, 건강표시 유형을 확인하는 기준
- 미국 NIH ODS: 성분별 Fact Sheet가 있으면 근거 요약에 참고할 수 있는 공공 자료
- 미국 FTC: 효능을 강하게 주장하는 광고가 충분한 근거를 갖췄는지 보는 광고 기준

공식 자료로 확인하기 전까지는 `확인 필요`로 표시합니다.

## 근거 수준 표현

근거 수준은 사용자가 오해하지 않도록 짧고 보수적으로 씁니다.

예시:

- `확인 필요`: 공식 자료나 원문 확인이 아직 부족한 상태
- `제한적 근거`: 일부 자료는 있으나 효과를 단정하기 어려운 상태
- `공식 표시 확인`: 국내 기능성 표시 또는 공식 자료 확인이 된 상태

새로운 표현을 추가할 때는 사용자가 쉽게 이해할 수 있는 한국어를 우선합니다.

## 후기 표현 원칙

후기는 제품 선택에 도움이 될 수 있지만, 효능을 증명하는 자료는 아닙니다.

따라서 리포트에서는 `후기에서 자주 보이는 반응`처럼 표현합니다.

좋은 표현:

- 복용 편의성이 자주 언급됩니다.
- 개인별 체감 차이가 함께 언급됩니다.
- 속 불편함 여부를 확인하는 후기가 보입니다.

피해야 할 표현:

- 효과가 입증되었습니다.
- 후기가 효능을 증명합니다.
- 대부분의 사용자가 같은 효과를 봤습니다.

## 샘플 데이터 구조

현재 샘플 데이터는 `supplement-evidence-v1` 구조를 사용합니다.

필수 항목:

- `ingredientId`: 원료를 구분하는 ID
- `nameKo`: 한국어 원료명
- `summary`: 원료 요약
- `functionalIngredientStatus`: 국내 기능성 원료 인정 여부 상태값
- `functionalIngredientStatusLabel`: 화면에 표시할 상태 문구
- `functionalIngredientNote`: 인정 여부에 대한 설명
- `regulatoryStatus`: 한국/미국 공식 기준 확인 결과
  - `consumerQuestion`: 소비자 관점의 질문
  - `consumerAnswer`: 질문에 대한 짧은 답
  - `buyerValue`: 구매 판단에 주는 의미
- `claims`: 효능/근거 요약 목록
- `cautions`: 주의사항 목록
- `reviewSummary`: 후기에서 자주 보이는 반응 요약
- `references`: 참고자료 목록

필수 항목이 빠지면 리포트 생성 테스트에서 오류가 나도록 관리합니다.

## 공개 샘플의 범위

공개 샘플은 사용자가 가격 비교 리포트의 구조를 이해할 수 있는 수준의 요약을 목표로 합니다.

다음 내용은 공개 샘플에 넣지 않습니다.

- 출처가 불명확한 효능 단정
- 검증되지 않은 치료 효과 표현
- 개인 건강 상태에 맞춘 복용 권고
- 특정 판매처를 부당하게 유리하게 보이게 하는 표현

## 향후 개선 방향

향후 실제 자료를 추가할 때는 다음 순서로 확장합니다.

1. 공식 자료 확인
2. 논문 또는 임상자료 요약
3. 제품 라벨과 판매 페이지 정보 구분
4. 후기에서 자주 보이는 반응 정리
5. 리포트에서 확인 필요 항목 표시

이 프로젝트는 영양제 선택을 돕는 가격 비교 도구이며, 건강 판단은 전문가 상담과 공식 자료 확인을 우선해야 합니다.
