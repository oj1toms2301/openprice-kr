# 영양제 근거 데이터 공개/비공개 운영 설계

## 목적

`openprice-kr`의 영양제 리포트는 가격만 비교하지 않는다.

사용자가 실제로 궁금해하는 것은 다음에 가깝다.

- 이 제품이 얼마인가
- 1정 또는 1캡슐당 얼마인가
- 하루 복용량 기준으로 하루에 얼마인가
- 성분의 효능 근거가 어느 정도인가
- 국내 건강기능식품 기능성 원료로 인정되었는가

따라서 이 프로젝트는 영양제 가격 비교와 간단한 효능/근거 요약을 함께 제공하는 방향으로 확장한다.

다만 모든 상세 근거 자료를 공개 저장소에 그대로 올리면, 운영자가 만든 조사 자료와 WordPress 콘텐츠가 쉽게 복제될 수 있다. 그래서 공개 저장소와 비공개 자료 저장소의 역할을 나눈다.

## 기본 방향

운영 구조는 다음 4단계로 잡는다.

```text
비공개 상세 근거 DB
→ 공개 요약 데이터
→ GitHub 공개 HTML 리포트
→ WordPress 상세 해설
```

개발자 용어로는 `private evidence database + public summary dataset + static report generator + curated content site` 구조다.

쉬운 말로는, 자세한 조사 자료는 비공개로 관리하고, 공개 저장소에는 누구나 쓸 수 있는 요약 자료와 HTML 생성 도구를 제공하는 방식이다.

## 공개 저장소의 역할

GitHub 공개 저장소는 오픈소스 프로젝트로서 독립적인 가치가 있어야 한다.

따라서 공개 HTML 리포트는 WordPress 없이도 기본 판단이 가능해야 한다.

공개 저장소에 포함할 수 있는 정보:

- 성분명
- 가격 비교 후보
- 제품별 총량
- 1정, 1캡슐, 1포 등 단위당 가격
- 하루 복용량
- 하루 비용
- 국내 기능성 원료 인정 여부
- 대표 효능 주장
- 효능별 간단한 근거 등급
- 짧은 효능/근거 요약
- 핵심 주의사항
- 최소한의 참고자료

공개 요약은 너무 빈약하면 안 된다. GitHub 소스만 사용하는 사람도 어느 정도 근거가 포함된 HTML을 생성할 수 있어야 한다.

## 비공개 자료 저장소의 역할

비공개 저장소는 상세 조사 자료와 운영 판단을 보관한다.

비공개로 관리할 정보:

- 논문별 상세 요약
- 임상시험 국가, 대상자 수, 기간, 용량
- 효능별 수치 변화
- 원자료 발췌와 내부 메모
- 근거 등급을 매긴 이유
- LLM에 넣는 상세 프롬프트
- WordPress 긴 원고
- SEO 문장과 운영 메모
- 제휴 링크 또는 수익화 관련 메모

이 자료는 공개 요약을 만들기 위한 원천 자료다. 공개 저장소에는 이 전체를 그대로 복사하지 않는다.

## WordPress의 역할

WordPress는 공개 저장소보다 더 깊고 읽기 쉬운 상세 해설 사이트로 운영한다.

WordPress에 넣을 수 있는 차별화 포인트:

- 효능별 신뢰도 설명
- 임상시험이 어느 나라에서 몇 명을 대상으로 진행되었는지
- 몇 주 동안 어떤 용량을 먹었는지
- 체중, 혈압, 피로도 같은 결과가 실제로 얼마나 바뀌었는지
- 소비자가 이해하기 쉬운 해석
- 이런 사람에게는 의미가 있고, 이런 사람에게는 애매하다는 판단
- 부작용, 상호작용, 복용 전 주의사항
- 업데이트 이력

WordPress는 GitHub 리포트의 필수 출처가 아니다.

GitHub 리포트의 근거 출처는 가능하면 공식 자료, 논문, 기능성 원료 자료 같은 직접 출처로 둔다. WordPress는 더 자세한 설명을 제공하는 별도 콘텐츠 채널로 본다.

## WordPress 링크 노출 원칙

GitHub 공개 HTML 리포트에는 WordPress 링크를 기본 노출하지 않는다.

이유:

- 오픈소스 도구가 개인 사이트 유입용으로 보일 수 있다.
- 근거 요약이 일부러 짧게 작성된 것처럼 보일 수 있다.
- GPT 오픈소스 기여자 선정 관점에서도 신뢰도가 낮아질 수 있다.

따라서 기본값은 다음과 같다.

```json
{
  "showExternalDetailLinks": false
}
```

사용자가 직접 켠 경우에만 HTML 하단에 중립적으로 표시한다.

예시:

```text
추가 해설: 운영자가 제공한 외부 상세 문서
```

이 링크는 버튼처럼 강조하지 않는다. 가격 비교 표나 근거 요약의 핵심 위치에도 두지 않는다.

README에는 낮은 위치에서 한 번 정도만 언급할 수 있다.

예시:

```text
운영자는 일부 성분에 대해 별도 상세 해설 문서를 운영할 수 있습니다.
이 저장소의 리포트는 외부 문서 없이도 기본 요약을 확인할 수 있도록 설계합니다.
```

## LLM 공개 요약 생성 규칙

비공개 상세 자료에서 공개 요약을 만들 때 LLM을 사용할 수 있다.

하지만 LLM이 비공개 내용을 과도하게 공개하지 않도록 공개 규칙표를 둔다.

개발자 용어로는 `export policy`다.

공개 가능:

- 효능별 1~3문장 요약
- 근거 등급
- 국내 기능성 원료 인정 여부
- 대표 참고자료 일부
- 핵심 주의사항

비공개 유지:

- 논문별 긴 요약
- 상세 수치 표 전체
- 내부 판단 메모
- WordPress 원고 전문
- 수익화 관련 메모

공개 요약은 사람이 검토한 뒤 공개한다. 초기 단계에서는 LLM 자동 생성 결과를 바로 GitHub에 올리지 않는다.

## 첫 출시 순서

모든 성분을 조사한 뒤 한 번에 공개하지 않는다.

처음에는 한 성분으로 전체 흐름을 작게 검증한다.

권장 순서:

1. 비공개 상세 DB 구조를 만든다.
2. `잔티젠` 1개 성분을 깊게 조사한다.
3. 잔티젠 공개 요약본을 만든다.
4. WordPress에 잔티젠 상세글 1개를 먼저 올린다.
5. GitHub에는 가격 비교와 짧은 근거 요약이 포함된 잔티젠 HTML 리포트를 공개한다.
6. 같은 방식으로 `코엔자임Q10`, `가르시니아` 등으로 확장한다.

이 방식은 복제 위험을 줄이고, 공개 요약 수준과 WordPress 글 형식을 빠르게 검증할 수 있다.

## 데이터 구조 방향

공개 요약 데이터는 성분 단위와 제품 단위를 분리한다.

국내 기능성 원료 인정 여부는 단순 문장이 아니라 상태값으로 관리한다.

가능한 상태:

- `recognized`: 인정됨
- `not_recognized`: 인정되지 않음
- `needs_review`: 확인 필요
- `unknown`: 아직 조사하지 않음

성분 단위 데이터 예시:

```json
{
  "ingredientId": "xanthigen",
  "nameKo": "잔티젠",
  "functionalIngredientStatus": "needs_review",
  "functionalIngredientStatusLabel": "확인 필요",
  "claims": [
    {
      "claim": "체지방 감소 관련",
      "evidenceLevel": "검토 필요",
      "summary": "초기 공개 요약에서는 핵심 근거와 한계를 짧게 설명한다."
    }
  ],
  "cautions": [
    "임신, 수유, 질환 치료 중인 경우 전문가 상담이 필요할 수 있다."
  ],
  "references": []
}
```

제품 단위 데이터 예시:

```json
{
  "productName": "샘플 잔티젠 제품",
  "unitType": "캡슐",
  "unitCount": 60,
  "dailyServingCount": 2,
  "totalPrice": 30000,
  "unitPrice": 500,
  "dailyCost": 1000,
  "daysCovered": 30
}
```

## 표현 원칙

영양제 효능 표현은 조심스럽게 작성한다.

피해야 할 표현:

- 치료된다
- 확실히 효과가 있다
- 누구에게나 추천한다
- 먹으면 살이 빠진다

권장 표현:

- 일부 연구에서 관찰되었다
- 근거 수준은 제한적이다
- 국내 기능성 인정 여부는 별도로 확인이 필요하다
- 개인의 건강 상태에 따라 전문가 상담이 필요할 수 있다

이 프로젝트는 의료 조언을 제공하지 않는다. 가격 비교와 근거 요약을 돕는 정보 도구로 본다.

## 성공 기준

첫 확장 단계의 성공 기준은 다음과 같다.

- 잔티젠 1개 성분에 대해 비공개 상세 자료와 공개 요약 자료가 분리되어 있다.
- 공개 HTML 리포트에 가격 비교와 간단한 효능/근거 요약이 함께 나온다.
- 1정 또는 1캡슐당 가격, 하루 복용량, 하루 비용이 표시된다.
- 국내 기능성 원료 인정 여부가 표시된다.
- WordPress 링크는 기본 HTML에 노출되지 않는다.
- WordPress 상세글은 별도 콘텐츠로 존재한다.
- 사용자가 HTML 결과물을 직접 보고 검토한 뒤에만 다음 공개 작업을 진행한다.

## 아직 하지 않는 것

이번 설계에서 바로 하지 않는 것:

- 대규모 쇼핑몰 자동 크롤링
- 여러 성분의 전체 DB 공개
- WordPress 전체 사이트 완성
- 의학적 효능 판정 자동화
- LLM 결과의 무검토 자동 공개
- 제휴 링크 자동 삽입

초기 목표는 작게 검증 가능한 운영 흐름을 만드는 것이다.
